# Troubleshoot clusters and nodes

This section covers troubleshoot clusters and nodes. You will study Node Conditions And Host Diagnosis. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Distinguish unready, unschedulable and stale reporting.
- Trace kubelet and runtime dependencies.
- Interpret pressure, trust and connectivity evidence.
- Verify restored node responsibility without undoing intended policy.
