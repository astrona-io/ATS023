# Summary

Node observations distinguish health, reporting and intentional scheduling boundaries. The kubelet, runtime, host resources and communication path contribute different requirements to local workload service.

A node can keep some containers running while management deteriorates. Diagnose the failing responsibility and confirm current health and workload behavior while preserving deliberate maintenance and security settings.

The affected population narrows the scope, while evidence from the specific dependency establishes the cause. A fresh report with `False` points at the node's own subsystems, and a stale report that the node controller turned into `Unknown` points at the reporting path. Taints that the node controller adds are a consequence of that state, not its cause.
