# Service And External Request Troubleshooting

This module develops service And External Request Troubleshooting. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Trace discovery, Service selection and backend ports.
- Distinguish readiness from process existence.
- Separate transport, routing and application failures.
- Choose a correction for the first demonstrated broken relationship.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
