# Manage and evaluate container output streams

This section covers manage and evaluate container output streams. You will study Output Streams And Runtime Failure Evidence. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain standard output and supported log retrieval.
- Select container, instance and observation window.
- Interpret restart and termination evidence.
- Protect sensitive records and preserve useful diagnostics.
