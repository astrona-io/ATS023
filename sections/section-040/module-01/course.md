# Output Streams And Runtime Failure Evidence

This module teaches how to read the output streams of a container and the status records that describe how it ended. It shows which component produces each record, how to select the right Pod, container and instance, and how to prove a diagnosis.

## Learning Goals

- Explain standard output and supported log retrieval.
- Select container, instance and observation window.
- Interpret restart and termination evidence.
- Protect sensitive records and preserve useful diagnostics.

## Before You Start

Use the module playground for guided practice. Graded exercises use independent environments and follow the readings they practise.

## Reading Order

1. Selecting The Right Container Log And Time Window
2. Logs, Exits And Crash Loops
3. Guided Practice: Diagnose A Previous Container Exit
4. Summary
