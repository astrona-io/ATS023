# Summary

Container logs capture a supported process-output path rather than every internal file or infrastructure event. Identity, lifecycle instance and retention determine what evidence remains available.

Termination state, events and application records provide complementary observations. Correlate them with the failed operation, preserve sensitive data controls and avoid treating one familiar message as a complete diagnosis.

You can now connect a restart to the relevant process instance and evidence. A focused correction must change the cause, while repeated restarts alone can reproduce the same failure indefinitely.
