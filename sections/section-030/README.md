# Monitor cluster and application resource usage

This section covers monitor cluster and application resource usage. You will study Resource Observations And Capacity Diagnosis. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Compare specification, status, events and metrics.
- Confirm observation context and permissions.
- Distinguish measured usage from allocation and enforcement.
- Account for complete workload capacity requirements.
